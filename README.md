 #Object Detection and Recognition Project

This project trains a YOLO model (Ultralytics) to detect and recognise myself in images.

## Dataset
- 500+ annotated images of myself, stored on Google Drive
- Annotated for object detection

## Tools
- Python and Jupyter Notebook
- Ultralytics YOLO
- Scikit-learn (linear and logistic regression practice)
- Ollama with Llama 3.2 1B

## Contents
- Jupyter notebooks from my practice sessions
